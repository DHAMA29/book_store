CATATAN FOR DAN i++ C++

1. i++
i++ artinya nilai i bertambah 1.

Contoh:
int i = 0;
i++;
// i menjadi 1

Sama dengan:
i = i + 1;


2. FOR
Bentuk dasar:

for (int i = 0; i < jumlah; i++) {
    // kode
}

Artinya:
- int i = 0  -> mulai dari 0
- i < jumlah -> selama kondisi benar, ulangi
- i++        -> setiap selesai, i bertambah 1


3. CONTOH SEDERHANA

for (int i = 0; i < 5; i++) {
    cout << i << endl;
}

Hasil:
0
1
2
3
4

Urutannya:
i = 0 -> tampil -> i++
i = 1 -> tampil -> i++
i = 2 -> tampil -> i++
i = 3 -> tampil -> i++
i = 4 -> tampil -> i++
i = 5 -> berhenti


4. PENERAPAN ARRAY

string buku[3] = {"C++", "HTML", "Java"};

for (int i = 0; i < 3; i++) {
    cout << buku[i] << endl;
}

Hasil:
C++
HTML
Java

i digunakan untuk berpindah index:
i = 0 -> buku[0]
i = 1 -> buku[1]
i = 2 -> buku[2]


5. PENERAPAN MENJUMLAHKAN ANGKA

int total = 0;

for (int i = 1; i <= 5; i++) {
    total = total + i;
}

Hasil:
total = 15

Karena:
1 + 2 + 3 + 4 + 5 = 15


6. PENERAPAN MENAMPILKAN ANGKA GENAP

for (int i = 2; i <= 10; i += 2) {
    cout << i << endl;
}

Hasil:
2
4
6
8
10

Catatan:
i++ = tambah 1
i += 2 = tambah 2


7. PENERAPAN MENCETAK NAMA

for (int i = 0; i < 3; i++) {
    cout << "Zaka" << endl;
}

Hasil:
Zaka
Zaka
Zaka


INGAT PALING SEDERHANA:

for = perulangan
i = penghitung
i++ = i bertambah 1

Kalau melihat:
for (int i = 0; i < 5; i++)

Baca:
"Mulai dari 0, ulangi selama kurang dari 5, setiap putaran tambah 1."
